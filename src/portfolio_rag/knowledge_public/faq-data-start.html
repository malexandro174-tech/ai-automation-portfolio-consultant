Какие данные нужны для начала

Первая заявка

Существующая форма на сайте запрашивает имя, контакт и описание задачи. Компания может быть указана дополнительно. Пользователь сам подтверждает отправку.

Обсуждение задачи

Для предварительного разбора полезно описать текущий процесс, проблему, ожидаемый результат и используемые сервисы. Это рекомендуемый набор вопросов, а не требование передавать приватные базы или доступы в публичный чат.

Минимизация данных

Не отправляйте пароли, ключи, приватные записи встреч и персональные сведения клиентов в консультант. Для иллюстрации задачи используйте обезличенный пример. Конкретный безопасный способ передачи рабочих данных согласуется отдельно.
